# Examples for runic_galdr

This folder contains alternative scripts that demonstrate different ways of using the runic_galdr modules. To try one, edit the `<script>` tag in `index.html` to point to the desired example.

- **bindrune-builder.js** – Build a custom bindrune by adding runes with the number keys. Press `Space` to clear your selection. This shows how to compose multiple runes and render them together.
- **galdr-waves.js** – Cycle through every rune automatically, displaying each one with its corresponding galdr resonance animation. Press `Space` to pause or resume the cycle.
- **calendar-wheel.js** – Display the full runic wheel and highlight a new random rune every few seconds. Press `Enter` to toggle auto‑rotation on and off.

These examples are intentionally lightweight and self‑contained. They import the same modules as the main app and illustrate how to reuse the functionality in different contexts.
